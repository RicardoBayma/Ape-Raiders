# Ape Raiders
<p>Ape Raiders é jogo baseado no clássico jogo "Space invaders", mas a diferença que trazemos é divertida, pois pegamos a ideia do jogo  "Bloons TD 6" na qual substituimos a nave principal por um macaco e as naves inimigas serão balões. Temos um sistema de score, que quanto maior ele fica mais inimigos aparecem, eles ficam mais forte e mais rápidos também. Ao mesmo tempo a dificuldade aumenta, o personagem pode receber "boosts" aleatórios para aprimorar o personagem, que após estourar uma certa quantidade de balões, o Boost é ativado. O jogador terá 3 vidas, seja acertado três vezes e você perde. O objetivo do jogo é derrotar os inimigos e estourar o máximo de balões possíveis para bater o recorde.</p>
