# Ape Raiders
<p>Ape Raiders será um jogo baseado no clássico jogo "Space invaders", mas a diferença que trazemos é divertida, pois pegamos a ideia do jogo  "Bloons TD 6" na qual iremos substituir a nave principal por um macaco e as naves inimigas serão balões. Haverá um sistema de rodadas e cada rodada a dificulade aumenta, com mais inimigos e mais projéteis. Ao mesmo tempo a dificuldade aumenta, o personagem pode receber "boosts" aleatórios para aprimorar o personagem, podendo escolher entre algumas opções. O jogador terá 3 vidas, seja acertado três vezes e você perde. O objetivo do jogo é derrotar os inimigos e sobreviver até a última rodada.</p>
